{\textbf{Text-to-Fluid: Semantic Authoring of Fluid Simulation via Large Language Models}} {\sl Unity, Unity Shader Language, C++} \\
This project uses an LLM to analyze the emotions conveyed by user input and express them visually by adjusting properties (such as color) of an SPH fluid rendered in Unity. A generative model based on a variational autoencoder (VAE) and U-Net for generating stylized height maps and corresponding color textures. Integrated the Copernicus Data Space Ecosystem (CDSE) API to automate the acquisition and processing of global terrain data.\\
GitHub: \url{https://github.com/ECNUjohnny/llm-style-terrain-joint}\\
